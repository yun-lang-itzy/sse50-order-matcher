# 验证结果与发布范围

本次发布前重新执行 27 项测试，全部通过。原始输出见 [test-results.txt](test-results.txt)。日志中的 PyArrow sysctl 警告由沙箱读取 CPU 缓存信息受限导致，未影响测试结果。

2026-10-09 的全量回放审计覆盖 50 个证券，共 10,321,925 条事件；逐证券结果见 [replay-audit.json](replay-audit.json)。未知撤单、连续竞价被动订单引用缺失、超量扣减、重复新增均为 0。连续竞价快照核对 236,581 条，十档完全一致 67,480 条；其余差异尚未排除异步发布、时间对齐和重建偏差，不能声称精确复刻交易所。

测试覆盖规则边界、FIFO、部分成交、撤单释放、T+1、资金约束，以及主板和科创板真实数据的回放与会话恢复。浏览器交互验证在初次实现时完成，详见 README。
